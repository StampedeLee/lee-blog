# 博客搭建杂项记录

## 1. 创建项目与安装 VitePress

使用 VitePress 作为博客生成器。

安装：

```bash
npm add -D vitepress
```

说明：

- `npm add`：安装依赖
- `-D`：表示这是开发依赖（dev dependency）
- `vitepress`：使用的博客生成器

---

## 2. 项目结构

项目名称：

```
lee-blog
```

初始化后：

```
lee-blog

├── node_modules        ← VitePress 依赖
├── package-lock.json   ← 版本记录
├── package.json        ← 项目配置
```

---

## 3. 创建 Markdown 文件

VitePress 使用 Markdown 文件作为页面内容。

Windows 创建空文件：

```bash
type nul > index.md
```

这是 Windows 创建空文件的方法。

注意：
如果使用 VitePress 默认结构，Markdown 文件通常应该放在 `docs` 目录下。

例如：

```
docs
└── index.md
```

---

## 4. 创建 VitePress 配置目录

进入项目目录：

```bash
D:\Projects\lee-blog
```

创建配置文件夹：

```bash
mkdir docs\.vitepress
```

目录结构：

```
docs

├── .vitepress
│
└── index.md
```

---

## 5. 配置 VitePress

配置文件：

```
docs/.vitepress/config.js
```

内容：

```javascript
import { defineConfig } from 'vitepress'

export default defineConfig({

  title: 'Lee AI Lab',

  description: 'My AI learning notes',

  themeConfig: {

    nav: [
      { text: 'Home', link: '/' },
      { text: 'Notes', link: '/notes/' },
      { text: 'Projects', link: '/projects/' }
    ]

  }

})
```

---

## 6. package.json 配置

项目配置文件：

```
package.json
```

添加启动脚本：

```json
{
  "name": "lee-blog",
  "version": "1.0.0",

  "scripts": {
    "docs:dev": "vitepress dev docs"
  },

  "devDependencies": {
    "vitepress": "^..."
  }
}
```

---

## 7. 启动博客

运行：

```bash
npm run docs:dev
```

启动后即可通过本地地址访问博客。
