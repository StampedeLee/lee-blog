# 损失函数与激活函数

回看损失函数公式：
常见均方误差（MSE）：

$$
Loss=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y_i})^2
$$

先看模型训练的基本过程：

1. 计算预测结果与真实值之间的误差；
2. 对损失函数求导，计算梯度；
3. 根据梯度方向调整模型参数。

### 为什么要用非线性函数？


神经网络训练的目标是通过调整参数，使预测结果尽可能接近真实值。

损失函数衡量误差；
梯度下降负责调整参数；
而激活函数负责赋予网络非线性表达能力。

无论把多少个线性的结果叠加在一起，结果依然是线性的，没法拟合复杂的数据。


**所以要引入非线性函数！**


#### sigmoid函数
$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

将任意输入映射到0~1之间，可以看作概率。
所以不会造成**梯度爆炸**

导数：

$$
\sigma'(x) = \sigma(x) \cdot (1 - \sigma(x))
$$

特点：
导数计算也十分简洁。单调递增也不会破坏大小的特征信息。
其次越接近0概率越小。也就是天然适合处理二分类的任务

缺点：
进行过多层训练，会造成**梯度消失**，因为最大只有0.25
（受早期性能影响，不会进行过大的层训练）

于是这就引出了

#### Relu函数

sigmoid的问题在于：
即使信息可以传递，但梯度容易逐层缩小。
ReLU通过简单的分段线性结构解决了这个问题。

f(x)=max(0,x)

relu函导数是1和零，
**无论输入多深，几乎可以无损的传回输入层**

特点：
计算效率极其的高
同时带来了**稀疏激活性**
>稀疏激活性指神经网络中只有少部分神经元在面对某个输入时被激活，而大部分神经元输出接近于 0 的现象。

优势：

降低计算量：减少无效神经元参与计算；
提高特征表达能力：不同神经元可以专门负责不同特征；
缓解过拟合：减少模型对噪声的学习。

同时也带来了问题:**神经死亡**
>当 ReLU 神经元长期输出 0 时，该神经元进入“死亡状态”。
>原因：
ReLU函数,当输入 x < 0 时：f'(x)=0
>如果某个神经元的参数更新后，使其输入长期保持负数，那么它之后不会再被激活，也无法继续学习。


于是就有leaky relu和gelu的出现

### 关于为什么不用直接的非线性函数:
答案是数学可以，工程灾难。
带来全局关联


例如高阶多项式：

y=ax^3+bx^2+cx+d

1. 参数耦合严重；
2. 高阶多项式就像一根弹簧一样，牵一发而动全身。一个参数变化会影响整个函数；
3. 梯度计算困难；
4. 容易出现数值不稳定。

反向传播也因为多个多项式系数，变得非常灾难
线性调整方向和长短，其他则是调整弯折的关节

>Tip：通用近似定理（Universal Approximation Theorem）：
只要神经网络包含隐藏层，并使用非线性激活函数，那么通过足够多的神经元，它可以逼近任意连续函数

简单来说，神经网络并不需要人为设计复杂公式，而是通过大量简单的线性变换与非线性激活函数组合，逐渐学习复杂的数据规律。因此，非线性激活函数赋予了神经网络强大的表达能力。
