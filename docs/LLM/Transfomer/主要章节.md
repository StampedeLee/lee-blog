# Transformer 与大模型基础

## 梯度下降

核心思想：

找到损失函数下降最快的方向，然后沿着这个方向更新参数。

---

## RNN 与 Transformer 对比

### RNN、LSTM

特点：

- 串行计算，效率低；
- 只有单层结构，难以关注深层次语义特征；
- 长距离信息容易丢失。

### Transformer

特点：

- 并行计算；
- 堆叠多层 Transformer Block；
- 捕捉长距离依赖关系。

---

# Transformer 架构

Transformer 主要包含：

Embedding → 位置编码（Positional Encoding）→ 注意力机制（Attention）→ 残差连接（Residual Connection）→ FFN（Feed Forward Network）→ 输出层

---

# Tokenizer 与 Embedding

## Tokenizer

原始文本处理流程：

原始文本 → 分词处理 → Token 序列 → 词汇表映射（Token ID）→ Embedding

Tokenizer（分词器）：

- 不需要自己设计；
- 常见方法包括 BPE 等。

---

## Tokenizer 与 Embedding 区别

Tokenizer：

> 把原始文本切分成 token，并将每个 token 转换为整数 ID 的工具。

Embedding：

> 把离散的 Token ID 映射成连续的高维向量的过程。

---

## 为什么需要 Embedding？

因为：

> 语义分散在向量的许多维度和相对关系中。

词向量（Word Embedding）可以：

- 表征一个单词和另一个单词之间的语义关系；
- 将离散符号转换为连续空间中的表示。

Token ID → Embedding Vector

---

# 位置编码（Positional Encoding）

## 为什么需要位置编码？

同一个 Token：

> 位置不同，语义可能不同。

Transformer 本身的 Attention 不包含顺序信息，因此需要额外加入位置编码。

作用：

> 让模型知道每个 Token 在句子中的位置。

---

## 位置编码公式

$$
PE(pos,2i)=sin(pos/10000^{2i/d_{model}})
$$

$$
PE(pos,2i+1)=cos(pos/10000^{2i/d_{model}})
$$

---

公式本质：

用很多组不同频率的 sin 和 cos 表示位置。

特点：

- 不同位置 → 不同编码，让模型知道词语的先后顺序；
- 固定长度 → 相同维度，每个位置生成相同维度向量；
- sin/cos → 稳定，编码值不会无限增长，避免影响训练；
- 多频率 → 长短距离兼顾，同时覆盖短距离和长距离关系。

-1 和 1 的范围天然表示位置关系。

---

# Transformer 前向传播

文本 → Token Embedding → 添加位置编码 → 多头注意力机制 → FFN → 输出层

---

# Attention 注意力机制

Attention 核心：

老师总结：

> Attention 考虑其他所有 Token 对当前 Token 在语义空间中的影响。

更直观：

> Attention 让模型决定“当前词应该关注哪些词，以及关注多少”，从而获得包含上下文信息的表示。

例如：

早期机器翻译：

- 每个词较为孤立；
- 难以考虑上下文。

后期 GPT：

- 考虑句子中各个词对于当前词的影响。

---

# QKV 机制

Q、K、V：

Query（Q）：

> 我需要关注什么？

Key（K）：

> 我有什么特征可以被匹配？

Value（V）：

> 真正要传递的信息。

---

计算：

$$
QK^T
$$

得到：

> 注意力得分矩阵。

（实际是转置，不需要考虑为什么能够计算）

---

注意力矩阵：

第 i 行，第 j 列：

表示：

> 位置 i 的 Token（作为 Query）对位置 j 的 Token 的影响。

然后：

信息 × 关系 = 影响

先计算 Token 之间的关系，再融合具体信息。

---

# Attention 公式

$$
Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V
$$

---

## Softmax

流程：

QK 原始值 → 使用 dk 进行缩放（消解长度影响）→ Softmax 归一化 → 概率分布

---

## 为什么除以 √dk？

因为：

Q 和 K 相乘后：

- 方差会随着维度增加；
- 点积值可能过大。

使用：

$$
\sqrt{d_k}
$$

进行缩放，可以消除这个影响，提高训练稳定性。

---

如果不使用 √dk 缩放：

- QKᵀ 点积值过大；
- Softmax 输出趋近 One-hot；
- 注意力集中于单个 Token；
- 信息融合能力下降。

---

# Attention 作用过程

原始单词 → 注意力计算（与 Query 连接）→ 上下文融合 → 语义增强

例如：

获得：

> “苹果树”

相关的语义特征。


## LayerNorm

LayerNorm：

对 *融合向量* 进行层归一化。

公式：

$$
LayerNorm(x)=\gamma * \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta
$$

LayerNorm 通过归一化输入，防止数值分布过于极端，避免 Softmax 退化为近似 One-hot，使训练更加稳定。（注：实验所得）

---

## 残差连接（Residual Connection）

没有残差连接时，深层网络容易出现梯度不稳定（消失/爆炸）、网络退化，同时逐层变换可能覆盖原始信息，导致有效语义特征丢失。

论文：ResNet

残差连接不直接用网络变换后的新表示替代原始向量，而是保留原始信息，将网络学习到的变化量加回原向量：

$$
输出=原输入+权重变换后的结果
$$

Transformer 的残差连接位置：

多头注意力层之后。

---

## LayerNorm位置

面试问题：

到底是在残差连接之前做 LayerNorm，还是残差连接之后做 LayerNorm？

LayerNorm 有两种方式：

Post-LN：

$$
y=LayerNorm(x+F(x))
$$

Pre-LN：

$$
y=x+LayerNorm(F(x))
$$

Post-LN 是原始 Transformer 设计，但随着模型规模增大，Pre-LN 因为更好的训练稳定性和梯度流动能力成为现代大语言模型更常用的结构。

原因：

Pre-LN 中残差分支可以直接传递梯度，不需要经过 LayerNorm，使梯度传播路径更加顺畅，适合几十层甚至上百层的深层 Transformer。

---

## FFN 和残差连接

FFN 核心作用：

把原来的非线性变化加入新的非线性影响，从而拟合更加复杂的语义之间的相互关系和影响。

FFN 处理过程：

升维 → 激活函数 → 降维 → 残差连接

为什么升维？

捕捉更深度空间中的语义信息和非线性信息。

Attention 负责 Token 与 Token 之间的信息交互，FFN 负责单个 Token 内部的信息加工和特征提取。

注意力残差连接 + FFN 残差连接 = Transformer 层级。

残差连接使每层学习对已有表示的增量变化，而不是完全替换原表示，从而保留有效语义并促进梯度传播，使深层 Transformer 能逐步融合和抽象更复杂的特征。

---

## 输出层

重点：

理解每一个架构用在什么地方。

### Decoder-only

只考虑前面的 Token 对后面的 Token 的影响。

流程：

输入 → 多层 Transformer → 提取最后一个 Token 表示 → 线性投影到词汇表空间 → Softmax 归一化概率分布 → 选择下一个词 → 更新序列

Decoder-only 模型本质上是一个“预测下一个 Token”的模型，通过不断根据已有上下文预测下一个词，从而逐步生成完整文本。

每一层 Decoder 都会让表示从低层词汇信息逐渐变成更抽象的语义特征。

---

## Encoder-only（BERT）

特点：

双向自注意力，没有 Mask 干扰注意力矩阵。

Encoder：

负责理解输入，把原始信息转换成机器内部表示（representation）。

Decoder：

负责利用表示生成输出。

BERT 核心作用：

将整个句子转换成一个语义向量，用于计算句子之间的相似度，之后 RAG 可能会使用。

BERT（Encoder-only）和 Decoder-only（GPT）的核心区别：

是否进行自回归生成。

BERT：只预测一次。

Decoder-only：不断预测下一个 Token。

总结：

Decoder-only：关注“接下来是什么”。

Encoder-only：关注“这句话是什么意思”。

---

## Encoder-Decoder

架构：

Encoder + Decoder

包含：

自注意力（Self-Attention）+ 交叉注意力（Cross-Attention）

编码器：编码器由多个相同的层堆叠而成，每一层都包含两个子层：自注意力机制和前馈神经网络。
编码器的任务是将输入序列转换为一系列连续的表示，这些表示同时包含了输入序列的每个元素的上下文信息。

解码器：解码器也由多个相同的层堆叠而成，每一层有三个子层：两个自注意力层和一个前馈神经网络。

第一个自注意力层只允许关注到前面的位置，第二个自注意力层则接收编码器的输出作为K和V。
