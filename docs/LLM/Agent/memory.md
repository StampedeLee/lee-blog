为什么需要Agent Memory? 因为上下文窗口有限

> agent memory 相对比较前沿，或者说没有形成一个定式的设计系统，最核心的一定离不开四个流程
> Storage, Write, Manage, Read

论文小结：
1. **Interactive Simulacra**
   - 记忆流增量更新、反思、读取
   - 人类在大脑中增量记录今天发生的事情，用这些记忆去判断下一步行动

2. **MemGPT**
   - 储存结构与管理（压缩、队列机制）
   - 朝着 LLM Agent 系统化方向演变

3. **SUEVEY**
   - 写入与管理
   - 包括写入、管理和读取（检索模式）
   - 明确地定义了 Memory 和 Agent 的集成过程

4. **Mem0**
   - 进一步定义更新与管理的操作规范
   - 使用图结构存储记忆
>特点：增量处理：只处理新信息 智能决策：LLM自动更新ADD/UPDATE/DELETE/NOOP 图增强：支持复杂关系和多跳推理

5. **A-MEM**
   - 优化检索和管理机制

上下文工程：**将来自不同来源和层面的信息进行筛选、组织与整合，并将其以合适的结构提供给大模型，使模型能够按照任务要求输出最恰当的结果。**
